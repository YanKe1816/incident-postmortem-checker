Incident Postmortem Checker

Organizes explicitly stated incident timelines and follow-up actions, and checks postmortem completeness using only the material supplied by the user.

Website: https://incident-postmortem-checker.sidcraigau.workers.dev

MCP Endpoint: POST https://incident-postmortem-checker.sidcraigau.workers.dev/mcp

Support Email: sidcraigau@gmail.com

What this app does

  • Extracts explicitly written incident timeline events.
  • Extracts explicitly written follow-up action items.
  • Checks postmortem completeness against checklist requirements supplied by the user.

When to use this app

  • Organizing existing incident postmortem material.
  • Extracting a timeline from postmortem text.
  • Extracting action, owner, and due date details from supplied notes.
  • Checking whether supplied material is missing explicit checklist items.

What input it accepts

  • Incident postmortems.
  • Incident timelines.
  • Follow-up action notes.
  • Completeness checklists.
  • Related text supplied by the user.

What output it returns

  • Structured timeline events.
  • Structured action lists.
  • Checks showing covered, missing, or partially covered items.
  • Source evidence or error information tied to the result.

Available tools

  • extract_incident_timeline: extracts explicit incident events and impact statements.
  • extract_postmortem_actions: extracts explicit follow-up actions, owners, deadlines, and evidence.
  • check_postmortem_completeness: checks supplied postmortem text against supplied requirements.

MCP endpoint

Use POST /mcp for JSON-RPC MCP requests.

What this app does not do

  • Does not access external incident management systems.
  • Does not investigate incidents or infer unstated facts.
  • Does not execute fixes or remediation.
  • Does not contact action owners.
  • Does not modify or publish postmortems.
  • Does not guarantee that postmortem content is true or complete in the real world.

Data handling

Input is used to process the current request. See the Privacy Policy for more detail.
