Privacy Policy

Incident Postmortem Checker processes text supplied by the user for read-only incident postmortem extraction and completeness checks.

Data collected

The app processes user-submitted incident postmortem text, timeline material, action notes, completeness checklists, optional source labels, and necessary request information.

How input is used

Input is used only to perform the extraction or completeness check requested by the user for the current request.

How output is generated

Output is generated from material supplied by the user. The app does not supplement facts through external systems and should not be treated as verification of real-world status.

Retention

The app does not operate its own database for storing submitted postmortem content. Infrastructure providers may process limited request data as necessary to operate and secure the service.

External sharing

The app does not sell user input and does not share user input for advertising purposes.

External API policy

The current tools do not call third-party business systems to complete extraction or completeness checks. Hosting and platform infrastructure may still process requests to operate the service.

Account and login policy

The app itself does not provide a separate user account or login system.

User controls

  • Avoid submitting unnecessary sensitive information.
  • Contact support with privacy questions.
  • Use host platform controls to manage conversation content where available.

Read-only boundary

The app does not modify, publish, or delete incident records, and it does not execute action items.
